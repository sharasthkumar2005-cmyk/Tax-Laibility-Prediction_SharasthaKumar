# 💰 Tax Liability Prediction Using Machine Learning

An academic Machine Learning project that predicts a taxpayer's estimated tax liability based on their financial information, presented through an interactive Streamlit web application.

---

## 📌 Project Overview

This project demonstrates the complete Machine Learning workflow for a regression problem:

```
Dataset  →  Preprocessing  →  Model Training  →  Evaluation  →  Streamlit App
```

A user enters their financial details (income, deductions, investments, etc.) into the web interface, and the trained ML model instantly predicts their estimated tax liability in Indian Rupees (₹).

## 🚀 How to Run the Project

### Step 1 — Install Dependencies

```bash
pip install -r requirements.txt
```

### Step 2 — Train the Model

```bash
python train_model.py
```

> **Windows users:** If you see a `UnicodeEncodeError`, run with the UTF-8 flag:
> ```bash
> python -X utf8 train_model.py
> ```

This will:
- Load and inspect the dataset
- Preprocess the features
- Train and compare two models (Linear Regression vs Random Forest)
- Save the best model as `tax_liability_model.pkl`
- Save evaluation metrics as `model_metrics.json`

### Step 3 — Launch the App

```bash
streamlit run app.py
```

Open your browser at **http://localhost:8501** to use the app.

## 🤖 Machine Learning Details

### Q1. What is Tax Liability Prediction?
Tax Liability Prediction means using historical taxpayer data to train a computer model that can estimate how much tax a person owes, based on their income and deductions — without manually applying complex tax rules.

### Q2. Why Machine Learning?
Traditional tax calculations require applying specific rules (tax slabs, deduction limits, etc.). Machine Learning learns patterns from past data automatically, making it faster and more flexible — especially useful for demonstration and academic purposes.

### Q3. What is the Target Variable?
**`Tax_Liability_INR`** — the amount of tax a person is estimated to owe.

### Q4. What are the Input Features?
Age, Employment Type, Annual Income, Other Income, Deductions, Investments, Home Loan Interest, Health Insurance Premium, and Previous Tax Paid — **9 features in total**.

### Q5. Which ML Algorithm was Selected?
**Random Forest Regressor** (if it outperforms Linear Regression on R², otherwise Linear Regression is selected automatically).

### Q6. Why Random Forest?
- It is an *ensemble model* — it builds 100 decision trees and averages their predictions.
- It handles **non-linear relationships** well (tax rules are not purely linear).
- It is **robust to outliers** (very high or very low incomes).
- It requires minimal data preprocessing and works well on small datasets like this one.

### Q7. What is R²?
**R² (R-squared)** measures how well the model's predictions match the actual values.
- **R² = 1.0** → Perfect prediction.
- **R² = 0.0** → The model is no better than simply guessing the average.
- **Example:** R² = 0.85 means the model explains 85% of the variation in tax liability.

### Q8. What is MAE?
**MAE (Mean Absolute Error)** is the average rupee difference between the model's predictions and the actual values.
- **Example:** MAE = ₹5,000 means on average the model's predictions are off by ₹5,000.
- Lower MAE is better.

### Q9. How does the Streamlit app make predictions?
1. The user fills in the form with their financial details.
2. The app creates a pandas DataFrame with those exact values.
3. The DataFrame is passed through the **saved ML pipeline**, which automatically applies the same preprocessing (StandardScaler + OneHotEncoder) that was applied during training.
4. The model outputs the predicted Tax Liability.
5. The app displays the result in a clean, readable format.
